Payroll to QuickBooks IIF

Drop paystubs and any other payroll documents the client gave you (payroll summaries and registers, EFTPS deposits, Form 941, state withholding and unemployment returns and payments). The tool reads them on this computer, checks that every paystub adds up, cross-checks all the documents against each other, builds one payroll journal entry for each pay date, and gives you an .iif file to import into QuickBooks Desktop (File › Utilities › Import › IIF Files). Nothing leaves this computer.
